# Research and design references

These are primary-source references for the workflow concepts. This project implements its own small engines; it does not claim integration with or equivalence to these platforms.

- [Dagster: software-defined assets and lineage](https://docs.dagster.io/guides/build/assets) — dependency relationships and asset-oriented investigation.
- [Dagster: precision data with asset selection](https://dagster.io/blog/updated-asset-selection-syntax) — investigating relevant subsets of a lineage graph.
- [Great Expectations: define expectations](https://docs.greatexpectations.io/docs/core/define_expectations/) — explicit, verifiable assertions about data.
- [Great Expectations: run validations](https://docs.greatexpectations.io/docs/core/run_validations/) — evaluate assertions against a dataset and inspect outcomes.
- [Pyodide 0.27.7 documentation](https://pyodide.org/en/0.27.7/usage/webworker.html) — execute Python in a background browser worker.

Product interpretation: make the model editable, expose the evidence behind an outcome, and let a visitor compare scenarios. The visual direction is original: light glass panels, restrained accent colors, dense investigation views, and a shared portfolio navigation rail.
