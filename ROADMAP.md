## Candidate contributions — not implemented

- Add a synthetic policy-boundary regression case, with an explanation of the expected result.
- Add accessible chart descriptions or keyboard improvements verified in the browser.
- Add a user-guide walkthrough for a realistic synthetic edge case.
- Evaluate a larger input with a documented environment and retained fixture before making a performance claim.

Discuss larger changes in an issue before implementation. A roadmap item is not a shipped capability or a promised delivery date.
