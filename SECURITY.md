# Security reporting

Report a suspected vulnerability privately to **kazimuzammil99@gmail.com** with the repository name, affected version, synthetic reproduction steps and potential impact. Do not post credentials or sensitive example data in public issues. Acknowledge that this is independently maintained software; there is no guaranteed response-time or support SLA.

Local development APIs are loopback utilities, not authenticated public services. Browser apps download a pinned Python runtime from a CDN. Review exported experiments before sharing: full experiment exports can include their inputs. Review Desk exports can contain field names, queries or document titles even when cell values are omitted.
